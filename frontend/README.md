# Hellopass 前端开发文档

## 项目概述

Hellopass 是一个简洁、安全的密码管理器前端应用，采用 Vue 3 + 原生 JavaScript 开发，不依赖外部资源，界面简洁明了。

## 技术栈

- **Vue 3**: 渐进式 JavaScript 框架
- **原生 JavaScript**: 不依赖外部 JS 库
- **CSS3**: 原生样式，响应式设计
- **HTML5**: 语义化标签

## 项目结构

```
frontend/
├── index.html              # 主页面
├── src/
│   ├── components/         # Vue 组件
│   │   ├── PasswordList.vue        # 密码列表组件
│   │   ├── AddPasswordForm.vue     # 添加密码表单
│   │   └── ExportForm.vue         # 导出表单
│   └── README.md          # 组件说明
├── package.json           # 依赖配置
└── README.md             # 本文档
```

## 核心功能

### 1. 登录认证
- 主密码验证
- 会话记住功能
- 安全退出

### 2. 密码管理
- 添加新密码
- 查看密码列表
- 搜索和筛选
- 复制密码
- 删除密码

### 3. 密码生成
- 自动生成强密码
- 可配置密码长度
- 可选字符类型
- 实时密码强度检测

### 4. 导出功能
- 多选导出
- 加密/明文格式选择
- 导出选项配置
- 导出预览

## 组件说明

### PasswordList.vue
**功能**: 密码列表显示和管理
- **props**:
  - `passwords`: 密码数据数组
  - `selectedPasswords`: 已选择的密码ID集合
  - `loading`: 加载状态
  - `searchQuery`: 搜索查询

- **events**:
  - `select`: 选择密码
  - `copy`: 复制密码
  - `edit`: 编辑密码
  - `delete`: 删除密码

### AddPasswordForm.vue
**功能**: 添加/编辑密码表单
- **props**:
  - `existingPassword`: 现有密码数据（编辑时使用）

- **events**:
  - `save`: 保存密码
  - `close`: 关闭表单

- **features**:
  - 表单验证
  - 密码强度检测
  - 自动密码生成
  - 标签管理

### ExportForm.vue
**功能**: 密码导出表单
- **props**:
  - `passwords`: 密码数据数组

- **events**:
  - `export`: 执行导出
  - `close`: 关闭表单

- **features**:
  - 多选功能
  - 格式选择
  - 导出预览
  - 安全提醒

## 安全考虑

### 1. 前端安全
- 不存储敏感数据
- 密码输入框使用 type="password"
- 复制后自动清除剪贴板
- 防止XSS攻击

### 2. 数据安全
- 所有密码数据加密传输
- 不记录敏感信息到日志
- 安全的表单验证

### 3. 用户体验安全
- 密码强度实时提示
- 危险操作确认
- 安全提示信息

## 开发指南

### 1. 添加新功能
1. 在相应组件中添加功能逻辑
2. 更新样式保持一致性
3. 添加必要的注释
4. 测试功能完整性

### 2. 修改样式
1. 遵循现有的颜色和间距规范
2. 保持响应式设计
3. 测试不同屏幕尺寸
4. 确保可访问性

### 3. 性能优化
1. 避免不必要的重新渲染
2. 使用事件委托减少事件监听器
3. 优化图片和资源加载
4. 保持代码简洁高效

## 部署说明

### 1. 静态部署
- 直接部署 `index.html` 及相关资源
- 支持 CDN 或静态服务器
- 无需构建过程

### 2. 开发环境
- 直接在浏览器中打开 `index.html`
- 使用 Vue DevTools 调试（可选）
- 本地文件访问可能受限

### 3. 生产环境
- 压缩 HTML、CSS、JavaScript
- 配置正确的 MIME 类型
- 启用 HTTPS
